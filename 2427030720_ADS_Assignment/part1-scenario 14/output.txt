CONCLUSION
Fixed-length DNA encoding requires 2 bits per base.
For the AT-rich sequence, Huffman coding should
benefit from the unequal symbol frequencies.
For the uniform sequence, all four bases are equally
frequent, so Huffman coding should approach 2 bits/base.
The actual measured values above should be used in
the report and observation section.
